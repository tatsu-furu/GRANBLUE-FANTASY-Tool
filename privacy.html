プライバシーポリシー

最終更新日：2026年9月27日

GRANBLUE FANTASY Tool（granbluefantasy.tools.alt4l.dev、以下「本サイト」）で扱う情報について説明します。本サイトは個人が運営するファン制作のツールで、株式会社Cygames とは関係ありません。

1. ブラウザ内に保存する情報

入力した編成・ムーブ・シート・設定などは、お使いのブラウザ（localStorage）に保存されます。これらは運営者のサーバーには送信されず、ブラウザのデータを消去すると削除されます。

2. 共同編集（ルーム）で保存する情報

ムーブ表ツールでルームを作成・参加した場合、次の情報を Google の Firebase Realtime Database に保存し、同じルームの参加者と共有します。

  • ルーム名、表示名（任意に入力したもの）
  • 編成（キャラ名・アビ名・召喚石・アイコン画像など）、共有シート、メモ
  • スクショ置き場にアップロードした画像（ブラウザ内で縮小してから保存）
  • 参加中であることを示す一時的な情報（ページを閉じると消えます）

ルームの内容は、ルームのリンクを知っている人なら誰でも閲覧・編集できます。個人情報や他人に見られて困る情報は入力しないでください。保存された内容は自動では削除されません。削除を希望する場合は下記の連絡先までご連絡ください。

3. Googleアカウントの利用（スプレッドシートへの書き出し）

共有シートの「Googleに直接書き出す」を使う場合に限り、Googleアカウントでのログインを求めます。

  • 要求する権限は https://www.googleapis.com/auth/drive.file（本サイトが作成したファイルにのみアクセスできる権限）だけです。お使いの Google ドライブ上のほかのファイルを閲覧・変更することはできません。
  • この権限は、共有シートの内容から新しい Google スプレッドシートを作成するためだけに使います。
  • ログインで得られるアクセストークンはブラウザのメモリ内でのみ使用し、運営者のサーバーやデータベースには保存・送信しません。ページを閉じると破棄されます。
  • Google から受け取った情報を、広告目的で使用したり、第三者に販売・提供したりしません。本サイトによる Google API から受け取った情報の使用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。

アクセスの許可は、Google アカウントの設定からいつでも取り消せます。

4. 外部サービス

本サイトは機能の提供のため、次の外部サービスを読み込むことがあります。これらのサービスでは、各社のポリシーに従って通信情報（IPアドレスなど）が扱われます。

  • Google（Firebase、Google Identity Services、Google Sheets API）
  • jsDelivr（ダメージ計算機の文字認識用データの配信）
  • gbfdata.com（古戦場ツールのボーダー情報の取得）
  • Ko-fi（支援ボタン）

ダメージ計算機のスクショ読み取りはブラウザ内で行い、画像を外部に送信しません。本サイトはアクセス解析や広告のための Cookie を使用していません。

5. お問い合わせ

本ポリシーや保存された情報の削除についてのお問い合わせは、tatsuki.furukawa@alt4l.dev までご連絡ください。

6. 変更

本ポリシーは必要に応じて変更することがあります。変更した場合は本ページで告知します。
