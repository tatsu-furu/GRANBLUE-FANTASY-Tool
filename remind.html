Discord リマインドBETA

団の Discord に、マルチの募集や古戦場の納品リマインドを送ります。今すぐ送るほか、日時を決めて予約もできます（毎日・毎週の繰り返しも）。

1. 送り先（Webhook）

送りたいチャンネルの Webhook の URL を登録します。URL はこのブラウザに保存され、「今すぐ送る」ではこのブラウザから Discord に直接送ります。

Webhook の URL の出し方
  1. Discord で、送りたいチャンネルの ⚙（チャンネルの編集）を開く（サーバーの「ウェブフックの管理」権限が必要です）
  2. 「連携サービス」→「ウェブフック」→「新しいウェブフック」
  3. 名前とアイコンを決めて「ウェブフック URL をコピー」

URL を知っている人は誰でもそのチャンネルに投稿できるので、人に見せないでください。使わなくなったら Discord 側でウェブフックを削除すれば、予約していたものも止まります。

    注意

    • ベータ版です。送信のタイミングや見た目は変わることがあります。
    • メンションは「なし」にすると、本文に @everyone と書いても通知は飛びません。
    • 予約は、このブラウザの見えない ID に結びついています。ブラウザのデータを消すと一覧から管理できなくなるので、その場合は Discord 側でウェブフックを削除して止めてください（削除されたウェブフックへの予約は自動で止まります）。
    • 1つのブラウザで予約できるのは 20 件までです。
    • サイト管理人は、迷惑な使われ方をしている予約を止める・削除することがあります。
